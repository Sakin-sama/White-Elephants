# 11575C's Code Base

This project would not be possible without numerous open source projects, including:

[Pros](https://github.com/purduesigbots/pros) and the [Pros Cli](https://github.com/purduesigbots/pros-cli), which provide an operating system for the Vex V5 brain.

[Lemlib](https://github.com/LemLib/LemLib) for their amazing Pros template.

[Motion View](https://github.com/lewispinstein-hue/MotionView), which provides live, gui-based debugging and logging.
